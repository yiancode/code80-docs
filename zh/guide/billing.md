# 计费与订阅

## 计费方式

Code80 平台采用按量计费模式，使用多少付多少。

## 计费规则

- 每次 API 调用会根据 Token 使用量计算费用
- 费用 = 上游实际消耗 × 分组倍率
- 不同分组可能有不同的倍率设置

## 订阅套餐

平台可能提供多种订阅方案：

- **按日额度**：每日固定额度，次日重置
- **按周额度**：每周固定额度
- **按月额度**：每月固定额度

## 余额查看

登录控制台后，在「我的订阅」页面可以查看：
- 当前有效订阅
- 已用额度 / 总额度
- 到期时间
- 额度重置倒计时

## 余额获取方式

- 购买订阅套餐
- 在线充值
- 兑换码兑换

## 费用优化建议

- 使用 `/compact` 等命令压缩上下文，减少 Token 消耗
- 精确描述需求，减少不必要的反复对话
- 选择合适的模型和参数配置
