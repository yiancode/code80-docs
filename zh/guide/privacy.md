# 隐私政策

*最后更新：2025 年 1 月*

## 1. 信息收集

本平台收集以下信息：
- 注册信息：用户名、邮箱等
- 使用数据：API 调用次数、Token 使用量等
- 设备信息：浏览器类型、操作系统等（用于优化服务）

## 2. 信息使用

收集的信息用于：
- 提供和维护服务
- 计费和账单管理
- 服务改进和优化
- 安全保障和异常检测

## 3. 信息保护

- 所有数据传输使用 HTTPS 加密
- API Key 采用加密存储
- 定期进行安全审计

## 4. 数据转发

- 用户的 API 请求会转发至上游 AI 服务商
- 转发过程中本平台不额外存储请求内容
- 上游服务商的数据处理受其各自隐私政策约束

## 5. 用户权利

- 用户可以随时删除自己的账号和数据
- 用户可以导出自己的使用记录
- 用户可以随时修改个人信息

## 6. 联系方式

如有隐私相关问题，请通过平台内的联系方式与我们沟通。
