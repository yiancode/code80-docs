# Gemini CLI 快捷键

Gemini CLI 在交互层面更偏向终端原生体验，公开资料里强调的是大上下文、Agent Mode 和 Google Search 等能力，而不是一套单独的快捷键体系。因此，这一页只保留稳定、通用、适合长期使用的操作。

## 常用快捷键

| 场景 | 快捷键 / 操作 | 说明 |
|------|---------------|------|
| 取消当前步骤 | `Ctrl+C` | 中断当前生成、搜索或执行中的任务 |
| 退出当前会话 | `Ctrl+D` 或直接退出终端 | 结束当前 Gemini CLI 会话 |
| 清屏 | `Ctrl+L` | 清空当前终端显示，保留会话内容 |
| 历史输入 | 上 / 下箭头 | 快速复用之前输入过的 prompt |
| 多行输入 | 按终端默认行为处理 | 以终端本身的输入能力为主 |

## 高频使用入口

当前文档站里已经覆盖的高频入口主要有这些：

```bash
gemini
gemini --version
```

对应场景如下：

- `gemini`：进入交互模式
- `gemini --version`：确认 CLI 是否安装成功，以及当前版本是否符合预期

## 实战建议

- 要分析大型项目时，优先在项目根目录启动 `gemini`，这样更容易发挥大上下文的优势。
- 遇到输出方向不对时，先用 `Ctrl+C` 中断，再补充更具体的约束重新发起任务。
- 长时间使用时，多利用上下箭头复用历史输入，可以明显减少重复描述。
- 如果你主要依赖联网和规划能力，可以把 Gemini CLI 当成“终端里的大上下文 + 搜索 + Agent”组合来使用，而不是只把它当成普通问答工具。
