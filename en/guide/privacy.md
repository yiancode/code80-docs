# Privacy Policy

*Last updated: January 2025*

## 1. Information Collection

The Platform collects:
- Registration info: username, email, etc.
- Usage data: API call counts, token usage, etc.
- Device info: browser type, OS, etc. (for service optimization)

## 2. Information Usage

Collected information is used for:
- Providing and maintaining services
- Billing and account management
- Service improvement and optimization
- Security and anomaly detection

## 3. Information Protection

- All data transmission uses HTTPS encryption
- API Keys are stored encrypted
- Regular security audits are conducted

## 4. Data Forwarding

- User API requests are forwarded to upstream AI providers
- The Platform does not additionally store request content during forwarding
- Upstream providers' data processing is subject to their own privacy policies

## 5. User Rights

- Users can delete their accounts and data at any time
- Users can export their usage records
- Users can modify personal information at any time

## 6. Contact

For privacy-related questions, please contact us through the Platform.
