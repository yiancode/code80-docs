# Gemini CLI Tips & Tricks

## Basic Operations

```bash
cd your-project
gemini
```

## Key Features

### Large Context Window

Gemini models support very large context, ideal for analyzing large codebases without frequent context compression.

### Agent Mode

Gemini CLI supports Agent Mode for automatic multi-step task planning and execution.

### Google Search Integration

Built-in Google Search capability for real-time access to the latest technical documentation and solutions.

## Productivity Tips

### Theme Settings

Configure in `settings.json`:
- `system`: Follow system
- `dark`: Dark mode
- `light`: Light mode

### Model Selection

Modify `GEMINI_MODEL` in the `.env` file to switch models.
