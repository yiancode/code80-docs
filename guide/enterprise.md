# 企业接入与平台能力说明

本页面向企业客户的技术尽调，说明 Code80 平台在模型支持、协议接入、性能、限流计费、安全合规与运维治理方面的真实能力。涉及具体延迟、可用性等运行指标，可按企业协议提供近 30 天的实测报告。

*最后更新：2026 年 7 月*

## 支持的模型与版本策略

平台同时支持四类主流模型家族：

| 模型家族 | 覆盖范围 |
|---------|---------|
| Claude 系列 | Opus / Sonnet / Haiku 各代主力版本 |
| GPT 系列 | GPT 主力对话、Responses、Embeddings、图像模型 |
| Gemini 系列 | Gemini 2.5 / 3.x 系列 |
| Grok 系列 | 以平台当前模型白名单和上游账号能力为准 |

**版本更新策略**：采用白名单 + 映射机制管理模型版本。官方发布新版本后由平台跟进上线，通常在官方发布当天至次日内完成接入。模型映射支持精确版本与通配符两种方式，企业客户可指定固定版本以保证调用稳定性，也可使用通配规则自动覆盖同系列新版本。

## 协议与接入方式

平台原生支持多套主流协议，并提供协议间转换，企业可沿用现有 SDK 直接接入：

| 协议 | 接入端点 |
|------|---------|
| Anthropic Messages | `/v1/messages`、`/v1/messages/count_tokens` |
| OpenAI Chat Completions | `/v1/chat/completions` |
| OpenAI Responses | `/v1/responses` |
| OpenAI Embeddings / Images | `/v1/embeddings`、`/v1/images/*` |
| Google Gemini | `/v1beta/models/{model}:generateContent`、`:streamGenerateContent` |

- Gemini 同时支持 Google AI Studio 与 Vertex AI 两种风格。
- 支持 Anthropic ↔ OpenAI 协议互转，覆盖工具调用（tools）、流式输出（streaming）与 token 计数，便于异构客户端统一接入。
- Grok CLI 通过 OpenAI 兼容的 Chat Completions / Responses 协议接入，具体扩展能力取决于所选上游账号与分组权限。

## 网络与性能

- **路由架构**：采用多账号池智能调度，而非单账号直连。具备负载感知选号（按并发与排队深度择优）、模型级路由规则、会话粘性（同会话默认 1 小时内绑定同一账号）、以及上游异常自动故障转移与重试。
- **代理健康治理**：对上游链路做健康度评分与隔离，自动规避异常节点。
- **延迟监控**：平台内置全链路埋点，统计 P50 / P90 / P95 / P99 与首 Token 延迟（TTFT）。实际延迟受所选模型与上游服务实时状态影响，具体数值可按需提供生产环境实测数据。
- **可用性**：对各渠道持续统计 7 / 15 / 30 天可用性。企业版支持签订可用性 SLA，具体目标值以商务协议为准。

## 限流与容量

- 默认采用**并发数控制**结合**上游限额透传**，而非固定 QPS/RPM/TPM。平台解析上游返回的限流信息并据此智能避让，最大化可用容量。
- 支持账号级、用户级并发配额，以及模型级限流配置。
- 企业客户可按需定制 Key 级配额（并发、速率或额度），以满足容量规划与成本控制需求。

## 计费方式

- **Token 级计费**，计量维度与官方一致：输入 Token、输出 Token、缓存创建、缓存读取分项计价，并支持长上下文与图像输出的差异化计价。
- 提供完整用量与成本明细，可按用户、API Key、账号组、模型多维度拆分。
- 最终单价以企业商务协议为准。

## 安全与合规

- **不存储对话内容**：平台不落库用户的 Prompt 与模型 Response 正文。常规用量记录仅包含 Token 计数、成本、模型名、请求 ID、耗时等元数据。
- **凭据脱敏**：日志中的 Authorization、API Key、Token、密钥等敏感字段在落库前自动脱敏处理。
- **错误诊断数据受控**：仅在请求出错时保留经脱敏、且有大小上限的请求体片段，用于排障，并设有默认保留期与自动清理。
- **数据保留可配置**：错误日志、监控指标等均支持配置保留周期与定时清理，可按企业合规要求调整。
- **资源来源**：平台接入方式均为官方授权通道，支持对接官方订阅账号、官方 API Key、AWS Bedrock 与 Google Vertex AI。企业客户可指定使用官方直采资源池。

## 运维与治理

平台提供完整的可观测能力，企业客户可获得：

| 维度 | 能力 |
|------|------|
| 调用量 | 按时间、模型、账号组、API Key、用户多维度统计与趋势 |
| 延迟 | P50–P99 分位、首 Token 延迟、延迟直方图 |
| 错误率 | 错误趋势、错误分布、故障分类、重试放大分析、代理健康度 |
| Token 用量 | 按用户 / API Key / 账号 / 模型拆分，含成本分项 |
| 告警 | 可配置阈值、观察窗口、持续时长与冷却，支持邮件通知 |

以上统计可在管理后台查看，并支持导出。
